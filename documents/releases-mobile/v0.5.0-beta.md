# Leather Engine Mobile v0.5.0-beta

First mobile release of Leather Engine for Android (ARM64) and iOS.

## Controls
- Hitbox with one lane per key, with multitouch support
- Arrows mode: tap the notes themselves at the bottom of the screen
- Pause button in the top right during songs
- Back button in the bottom right on menus and options
- Tap and swipe support on the Main Menu, Story Mode, Freeplay and Mods menus
- Vibration when hitting notes (Haptics)

## Options
New Mobile page in Options:
- Hitbox Mode
- Invisible Hitbox
- Invisible Pause Button
- Haptics
- Haptics Intensity (0.0 to 5.0)
- Screen Style (Original or Full)
- Storage Type

## Screen
- Full screen style uses the whole screen without stretching
- Notch and home indicator support on Android and iOS
- FPS counter now stays inside the screen with a background

## Storage
- Mods, replays and crash logs live in the chosen storage folder
- Bundled mods are copied on the first launch
- Falls back to a safe folder when the chosen one can't be used

## Other
- Updated libraries (Flixel 6.2.0, Lime 8.3.2, OpenFL 9.5.2, Polymod 1.8.0)
- Videos now play with hxvlc
- Lua scripts work on mobile
- Crash logs are saved to the crash folder
